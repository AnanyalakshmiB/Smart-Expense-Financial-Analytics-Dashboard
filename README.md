# 🚀 Finora – Smart Expense & Financial Analytics Dashboard

## 📌 About the Project

Finora is a front-end web development project designed to present financial information through a clean, user-friendly dashboard. It provides a visual overview of expenses, transactions, budgets, and financial analytics.

This project is the first step in my front-end development journey, where I am learning to transform ideas into practical web interfaces.

## 🎯 Features

* Dashboard with financial summary cards
* Analytics page with spending categories
* Transactions page displaying sample transaction records
* Budgets page with visual progress indicators
* Settings page with form elements
* Navigation between multiple pages
* Responsive styling for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Explore the dashboard and navigate between the pages.
